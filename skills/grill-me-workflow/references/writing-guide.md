# Write in plain English

Apply these rules to questions, recommendations, specifications, evaluations, and saved documents. They adapt the supplied Voice Align writing rules for this plugin.

- Write for a small-business owner who knows the work but may not know automation tools.
- Start with the first useful point.
- Use common words and complete sentences.
- Keep each sentence short. Use one idea and one clause where possible.
- Preserve material facts and exact names, labels, commands, and identifiers.
- Explain a required technical term at first use. Use full terms unless an exact product or source name uses a shortened form.
- Keep each fact in one place. Remove repeated previews and closing summaries.
- Use bullets for explanations and requirements. Number steps when order matters.
- Avoid metaphors, analogies, em dashes, filler, and vague claims.
- Label missing facts as unknown. Separate source observations, user reports, suggestions, and confirmed choices.
- When explaining how a process works, use Trigger, Inputs, What happens, and Outputs.

These are writing rules. They do not require access to a private logging base or another installed skill.
